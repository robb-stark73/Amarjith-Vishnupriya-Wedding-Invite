## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Once Pages finishes deploying, the public website URL will be shown in that settings page (typically `https://robb-stark73.github.io/our-wedding-website/`).

The RSVP form is front-end only: it prepares a response for the guest to copy and share. It does not send responses to the couple; connect a form service or provide a contact email to enable delivery.
